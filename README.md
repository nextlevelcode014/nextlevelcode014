# Hi, I'm NextLevelCode

Computer Science student focused on **systems administration and infrastructure**.
Everything I build follows the same three principles: **freedom, privacy and security**.
I like to keep an open mind, learn in public and collaborate on tools that respect their users.

---

## Running my own stuff
I'd rather run my own services than rent them, and I manage them the way I'd manage
production: as code. Terraform provisions LXC containers on a Proxmox node, and Ansible
configures everything inside them — on that node, on a Raspberry Pi 5 and on a Hetzner
VPS that faces the internet. Everything private is reached over Tailscale, secrets live
in my own Vaultwarden, and data at rest is encrypted with LUKS. New ideas go to a
separate lab I can destroy without touching any of it.

It's where I practice what I care about: Linux on every machine, owning my data,
and the same mindset that draws me to Bitcoin.

My code lives on my own Forgejo at [forge.nextlevelcode.pro](https://forge.nextlevelcode.pro),
and I write about the journey on [nextlevelcode.pro](https://nextlevelcode.pro).
